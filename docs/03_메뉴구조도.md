# 3. 메뉴구조도

`ui/` 폴더 구조를 그대로 따라 **창 → 위젯 → 메뉴** 3단계로 정리했다.

| 단계 | 뜻 | `ui/`에서의 위치 |
|-|-|-|
| **창** (Window) | 운영체제에 따로 뜨는 화면 하나 | `ui/<창 이름>/window.py` (관리 패널만 `ui/main/app.py`) |
| **위젯** (Widget) | 창 안에서 한 영역을 그리는 부품 | `ui/main/widgets/`, `ui/mobile/tabs/`, `ui/mobile/*_bar.py`, `ui/shared/` |
| **메뉴** (Menu) | 사용자가 누르거나 고르는 것 (버튼·탭·선택 목록·클릭) | 각 창·위젯 파일 안의 `Button`, `Combobox`, `Radiobutton`, 클릭 영역 |

## 3-1. 실행 흐름

```
python visualize.py
   │
   ▼
[W0] 로그인 창 ── 아이디·비밀번호 확인 (core/auth.py)
   │  ├─ 빈칸         → "아이디와 비밀번호를 모두 입력하세요."
   │  ├─ 틀림         → "아이디 또는 비밀번호가 틀렸습니다. (n/5)", 비밀번호 칸 비움
   │  ├─ 5회 연속 틀림 → 잠김 안내 후 프로그램 종료
   │  └─ 종료 버튼    → 프로그램 종료
   ▼ 성공
[W1] 관리 패널 (Home) + [W2] 시뮬레이터 + [W3] 모바일 앱 이 함께 뜬다
     [W4] 작물 시세, [W5] CCTV 는 Home의 메뉴로 연다
```

- 기본 계정: 아이디 `farmer` / 비밀번호 `evergrow`
- W2~W5는 닫아도 숨기기만 하므로 Home의 메뉴로 다시 연다. **W1(Home)을 닫으면 프로그램이 종료된다.**

```
│     │     └─ alerts.py          경고 알림 모음

│     └─ 메뉴: 기간 선택 [1일] [7일] [30일]
│
├─ [W5] CCTV 창                         cctv/window.py       CctvWindow
│     ├─ 위젯: 6개 구역 영상 (shared/cctv_view.py), 격리·방제 표시

├─ shared/cctv_view.py   여러 창이 같이 쓰는 위젯 (W1 상세, W3 CCTV 탭, W5)
└─ theme.py              모든 창이 같이 쓰는 색·글꼴·그래프 정의
```

## 3-4. 수업 예시 메뉴와의 대응

| 수업 예시 | 에버그로우 |
|-|-|
| (없음) | W0 로그인 창 — 허가된 사용자만 농장을 조작 |
| Home (메뉴 선택 화면) | W1 관리 패널 — 상태를 보면서 바로 메뉴를 고른다 |
| Menu1 재배 환경 설정 (값 직접 입력) | W1 `control_bar` 구역·작물 관리 (환경 값은 시뮬레이션이 만든다) |
| Menu2 환경 상태 확인 (낮음/적정/높음) | W1 `section_cards`·`detail_panel` — 적정 범위 띠, 빨간 값 표시 |
| Menu3 장치 관리 (자동/수동 ON·OFF) | 장치는 구역마다 자동 제어. W2 시뮬레이터에서 날씨·병충해를 일으켜 대응을 시험 |
| — | W3 모바일 · W4 시세 · W5 CCTV (확장 기능) |
