# 5. 시연과 향후 계획

## 5-1. 시연 시나리오 (약 1분)

실행: `python visualize.py`

0. **로그인** — 틀린 비밀번호로 한 번 시도해 오류 메시지(1/5)를 보여 준 뒤 `farmer` / `evergrow`로 로그인 → 관리 패널·시뮬레이터·모바일 창이 뜬다.
1. **정상 운전** — 관리 패널의 6개 구역 카드와 그래프의 초록 띠(적정 범위) 안에서 값이 유지되는 모습.
2. **한파** — 시뮬레이터에서 `한파 (바깥 -10°C)` 선택 → 로그에 `난방 ON` → 온도가 적정 범위로 복귀.
3. **병충해** — 구역을 골라 `🐛 병충해 발생` → `구역 격리` → 환기팬 닫힘 → `방제 완료, 격리 해제`. CCTV 화면에 "격리·방제 중" 표시.
4. **수확** — 수확 가능 카드 수확 → 비용·순이익 계산, 시세 창에서 판매한 작물 가격 하락 확인.

> 실시간 시연 실패에 대비해 같은 장면을 **영상으로 미리 녹화**해 둔다. 속도 슬라이더를 빠르게 하면 1분 안에 위 장면을 모두 볼 수 있다.

## 5-3. 향후 계획 (14–15주차)

- **계절별 관리** — 날씨에 계절 주기를 넣어 여름·겨울 운영을 비교
- **당도 관리** — 과채류(토마토·딸기) 품질에 당도 요소 추가
- **입력 검증 강화**, 테스트 정리
- **최종 보고서** — 문제 정의 → 자연어 → 메뉴구조도 → 설계 → 구현 → 테스트 → 한계
- 딥러닝 활용은 범위 밖 → 보고서에 향후 과제로만 기재
