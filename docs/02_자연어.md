# 2. 자연어 과정

프로그램이 하는 일을 사람의 말로 순서대로 정리한 것이다.

| 순서 | 자연어 설명 |
|-|-|
| 1 | 프로그램을 실행하면 **로그인 창**이 뜨고, 아이디·비밀번호가 맞으면 **관리 패널**(Home)·시뮬레이터·모바일 창이 열린다. 관리 패널에는 작물이 서로 다른 6개 구역 카드가 표시된다. |
| 2 | 사용자는 빈 구역을 선택하고 작물 목록(상추·토마토·딸기·파프리카·오이·시금치)에서 작물을 골라 **심는다**. |
| 3 | 시뮬레이터는 **10분 단위**로 시간을 진행하고, 바깥 날씨(기온·햇빛·구름)를 하루 주기로 바꾼다. |
| 4 | 각 구역의 센서가 **온도·습도·CO2·토양 수분·조도·양액(EC)** 을 측정한다. |
| 5 | 측정값을 **작물별 적정 범위**와 비교해 난방·냉방·가습·제습·환기·조명·급수·비료 장치를 **자동으로 켜고 끈다**. |
| 6 | 환경이 적정 범위를 벗어나면 식물의 **건강도가 떨어지고**, 적정하면 회복하며 생육 단계가 진행된다. |
| 7 | **병충해**가 감지되면 해당 구역을 격리(차폐)하고 방제한 뒤, 사라지면 격리를 해제한다. 방제가 반복 실패하면 갈아엎기를 안내한다. |
| 8 | 다 자란 작물은 **수확**하고, 전기·물·비료 비용과 **시세**로 순이익을 계산한다. |
| 9 | 모든 장치 작동과 이상 상태는 **로그와 모바일 알림**으로 남고, 사용자는 각 창을 닫거나 프로그램을 종료할 수 있다. |

## 입력 오류 처리

- 로그인 창에서 빈칸이 있으면 "아이디와 비밀번호를 모두 입력하세요.", 틀리면 "아이디 또는 비밀번호가 틀렸습니다. (n/5)"를 보여 주고 비밀번호 칸을 비운다. **5회 연속** 틀리면 안내 후 프로그램을 종료한다.
- 작물은 목록(콤보박스)에서만 고를 수 있어 잘못된 이름이 들어가지 않는다.
- 이미 작물이 있는 구역에 심기, 빈 구역 수확처럼 **할 수 없는 동작은 로그창에 안내 메시지**로 알려 준다.
  (예: "작물이 남아 있어 심을 수 없습니다. 먼저 수확하거나 정리하세요.")
- 자라는 작물을 갈아엎을 때는 **확인 창**을 한 번 더 띄운다.
- 시뮬레이션 속도는 슬라이더로 범위(20~1000ms) 안에서만 바꿀 수 있다.
