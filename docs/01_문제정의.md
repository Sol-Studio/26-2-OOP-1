# 1. 문제 정의

## 해결할 문제

농업 인구가 고령화되면서 일손이 줄고 있다. 온실 작물은 온도·습도·토양 수분·조도·양액 농도가 조금만 벗어나도 생육이 나빠지는데, **사람이 하루 종일 지켜보며 장치를 조작하기는 어렵다.**

→ 센서 값을 보고 **장치를 스스로 켜고 끄는 스마트팜**을 파이썬 객체지향으로 시뮬레이션한다.

## 구성 요소

| 구성 요소 | 내용 |
|-|-|
| 해결할 문제 | 농업 인구 고령화로 인한 노동력 감소 |
| 입력 데이터 | 작물 종류, 온도, 습도, CO2 농도, 토양 습도, 조도, 양액(EC) |
| 핵심 기능 | ① 적정 온습도·조도 유지 ② 급수·비료 살포량 조절 ③ 병충해 피해 최소화(구역 격리·방제) |
| 출력 | 냉난방, 가습·제습, 환기, 구역 차폐, 급수량, 인공조명 밝기, 비료 살포량 |
| 출력 결과 | 현재 환경 상태, 장치 작동 상태, 관리 로그·알림 |
| 확장 기능 | 로그인, 재배 비용·수익 계산, 작물 시세, CCTV, 모바일 앱 (구현) / 계절별 관리, 당도 관리, 딥러닝 (예정) |

## 수업 예시와의 차이 (우리 팀의 강점)

| 수업 예시 | 에버그로우 |
|-|-|
| 사용자가 값을 **직접 입력** | 날씨·장치·식물이 **시간에 따라 스스로 변하는** 시뮬레이션 |
| 구역 1개 | 작물이 다른 **6개 구역** 동시 관리 |
| 급수·환기·조명 3개 장치 | 난방·냉방·가습·제습·환기·조명·급수·비료 **8개 장치** |
| 낮음/적정/높음 판정 | 판정 + 식물 **건강도·생장도** 반영, 수확·수익까지 |
