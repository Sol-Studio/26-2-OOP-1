**합계 약 9분 25초** — 10분 이내. 7~10번(창별 위젯 표)과 16번(개념 대응표)은 표를 읽지 말고 핵심 한 가지만 짚고 넘긴다. 시간이 모자라면 4번(차이)을 생략한다.

## 예상 질문

- **Q. 수업에서 배운 내용은 어디에 썼나요?** — 16번 슬라이드 표. 대표 예로 13번의 Heater 클래스(상속·생성자·오버라이딩·다형성)를 보여 준다.

- **Q. 비밀번호는 어떻게 저장하나요?** — 원문이 아니라 솔트를 붙인 PBKDF2 해시만 저장하고, 5회 연속 틀리면 프로그램을 종료한다.

- **Q. 실제 센서와 연결할 수 있나요?** — `Sensor.measure()`만 실제 장비 값을 읽도록 바꾸면 된다. 제어 로직은 그대로 쓴다.
- **Q. 값을 직접 입력하는 메뉴는 없나요?** — 날씨와 장치가 환경을 바꾸는 시뮬레이션이라 직접 입력 대신 시뮬레이터에서 한파·폭염·병충해를 일으켜 대응을 시험한다.
- **Q. 왜 켜고 끄는 기준이 다른가요?** — 기준값 근처에서 장치가 계속 깜빡이며 켜지고 꺼지는 것을 막기 위해서(히스테리시스).
