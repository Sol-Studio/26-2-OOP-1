# 에버그로우(EverGrow) 스마트팜 시뮬레이터

농업 인구가 늙어가면서 일손이 줄어드는 문제를 풀기 위해, 온실의 온도·습도·토양 습도·조도·양액을 **자동으로 조절하는 스마트팜**을 파이썬으로 시뮬레이션하는 프로젝트입니다.

- **입력:** 작물 종류, 온도, 습도, CO2 농도, 토양 습도, 조도
- **출력:** 냉난방, 습도 조절, 구역 격리(차폐), 급수, 인공조명, 비료 살포
- **핵심 기능:** 적정 온습도·조도 유지, 비료량 조절, 병충해 피해 최소화

기획 내용은 [`main.md`](main.md)에 있습니다.

## 1. 설치하기

필요한 프로그램은 **Python**, **Node.js**, **Git**, 그리고 코드 편집기인 **VS Code**입니다.
서버는 파이썬 **FastAPI**, 화면은 웹(**React + three.js + Tailwind CSS**)으로 만들어서 브라우저에서 봅니다.

### 1-1. Python 설치

1. <https://www.python.org/downloads/> 에서 최신 버전(3.10 이상, 개발은 3.14에서 함)을 받습니다.
2. 설치 첫 화면 아래쪽의 **`Add python.exe to PATH`를 꼭 체크**한 뒤 `Install Now`를 누릅니다.
   이걸 빼먹으면 터미널에서 `python` 명령이 안 먹힙니다.
3. 설치가 끝나면 터미널(시작 메뉴 → `PowerShell` 또는 `cmd`)을 **새로 열고** 확인합니다.

   ```bash
   python --version
   ```

   `Python 3.x.x`처럼 버전이 나오면 성공입니다.

### 1-2. Node.js 설치

1. <https://nodejs.org/> 에서 **LTS** 버전을 받아 기본값으로 설치합니다.
2. 터미널을 새로 열고 `node --version`, `npm --version`이 나오면 성공입니다.

### 1-3. Git 설치

1. <https://git-scm.com/downloads> 에서 Windows용을 받아 설치합니다. 설치 중 나오는 선택지는 **전부 기본값 그대로 `Next`** 를 누르면 됩니다.
2. 터미널을 새로 열고 확인합니다.

   ```bash
   git --version
   ```

### 1-4. VS Code 설치 (권장)

1. <https://code.visualstudio.com/> 에서 설치합니다.
2. 실행 후 왼쪽 네모 아이콘(Extensions)에서 **Python** 확장(Microsoft 제작)을 설치합니다.
3. VS Code 안에서 `` Ctrl + ` ``(숫자 1 왼쪽 키)를 누르면 아래에 터미널이 열립니다. 앞으로 나오는 명령은 여기에 입력하면 됩니다.

### 1-5. 프로젝트 내려받기

GitHub 계정이 없다면 <https://github.com> 에서 먼저 만들고, 팀장에게 **아이디를 알려줘서 저장소 협업자(Collaborator)로 초대**받으세요. 메일로 온 초대를 수락해야 코드를 올릴 수 있습니다.

```bash
# 코드를 둘 폴더로 이동 (예: 바탕화면)
cd Desktop

# 저장소를 내 컴퓨터로 복사 (처음 한 번만)
git clone https://github.com/Sol-Studio/26-2-OOP-1.git

# 복사된 폴더로 이동
cd 26-2-OOP-1
```

VS Code에서는 `파일 → 폴더 열기`로 이 `26-2-OOP-1` 폴더를 열면 됩니다.

### 1-6. 라이브러리 설치 (처음 한 번, 그리고 `requirements.txt`·`package.json`이 바뀌었을 때)

```bash

# 화면(웹)
cd web
npm install
npm run build      # 화면을 web/dist로 빌드 → 서버가 같이 내보낸다
cd ..
```

## 2. 실행하기

프로젝트 폴더에서 (먼저 1-6에서 `npm run build`를 해 두어야 합니다):

```bash
python -m server
```

브라우저로 <http://127.0.0.1:8000> 에 들어가면 **로그인 화면**이 뜹니다. 기본 계정으로 로그인하세요.
넓은 화면에서는 왼쪽에 대륙을 점으로 찍은 지구본이 돌고(흰 점 = 우리 농장, 대한민국), 로그인하면 카메라가 농장 자리로 빨려 들어간 뒤, 관리 패널에서 3D CCTV가 전체 화면으로 떠서 "환영합니다" 인사와 함께 하늘에서 수직으로 내려와 제자리로 들어갑니다(로그인할 때만, 좁은 화면·'동작 줄이기'에서는 생략).

| 아이디 | 비밀번호 |
|-|-|
| `farmer` | `evergrow` |

빈칸이 있거나 틀리면 안내 문구가 나오고, **5번 연속 틀리면 로그인이 잠깁니다**(서버를 다시 켜야 풀림). 시뮬레이션은 서버에서 계속 돌아가므로 브라우저 창을 여러 개 열어도, 휴대폰으로 들어가도 모두 같은 농장을 봅니다.

| 화면 | 역할 |
|-|-|
| **관리 패널** | 3D 온실, 6개 구역 카드, 선택 구역의 장치·생육 단계·24시간 그래프·비용, 수확 기록, 로그 |
| **시뮬레이터** (위쪽 검은 띠) | 정지/재생, 10분 진행, 초기화, 속도, 계절 건너뛰기, 바깥 날씨(한파·폭염), 병충해 일부러 발생시키기 |
| **작물 시세** | 고른 작물의 캔들 차트(1일·1시간봉 / 7일·6시간봉 / 30일·일봉, chart.js)와 작물별 현재 시세 |
| **작물 설정** | 작물별 적정 조건(온도·습도·토양·EC·CO2 범위, 최소 조도) 고치기 |
| **모바일 앱** | 농장주가 휴대폰으로 보는 화면. 홈 / CCTV / 구역 / 알림 탭. 휴대폰 폭으로 접속하면 이 화면만 꽉 차게 뜬다 |

같은 와이파이의 휴대폰에서 보려면 `python -m server --host 0.0.0.0`으로 켜고 휴대폰에서 `http://(이 컴퓨터 IP):8000`으로 들어갑니다.

### 화면을 고치면서 개발할 때

`npm run build`를 매번 하지 않고, 저장하면 바로 바뀌는 개발 서버를 씁니다. 터미널 두 개를 엽니다.

```bash
# 터미널 1: 서버 (파이썬 코드를 고치면 저절로 다시 켜짐)
python -m uvicorn server.main:app --reload

# 터미널 2: 화면
cd web
npm run dev
```

그리고 <http://localhost:5173> 으로 들어갑니다. (`/api` 요청은 개발 서버가 8000번 서버로 넘겨 줍니다.)

> 그래픽 없이 모델만 확인하고 싶으면 `python main.py`를 실행하세요. 상추 한 구역을 키우면서 상태를 글자로 계속 출력합니다. 끌 때는 `Ctrl + C`.

## 3. 사용 방법

시뮬레이션은 **한 단계 = 10분**으로 저절로 흘러갑니다. 각 구역의 장치는 프로그램이 알아서 켜고 끄고, 사람은 **심기·수확·갈아엎기**만 합니다.

### 관리 패널
- **3D 온실** : 구역마다 온실이 한 동씩 있습니다(6동).
  - 구역을 고르면(온실 클릭, 구역 카드, 모바일 목록 어디서든) 카메라가 그 온실로 날아가 가까이 보여 줍니다. 왼쪽 위 **전체 보기**로 6동 전체 화면으로 돌아갑니다.
  - 마우스로 끌면 돌아가고 휠로 확대됩니다. 3D 화면을 한 번 누른 뒤 **W A S D**(또는 방향키)로 앞뒤·좌우, **Q / E**로 아래·위로 움직입니다. **Shift**를 누르고 있으면 빨라집니다.
  - 작물은 생장도만큼 자라고, 건강이 나빠지면 누렇게 변하고, 죽으면 쓰러집니다. 열매채소는 개화 뒤 열매가 맺힙니다.
  - 장치 8개가 온실마다 놓여 있고, 켜지면 움직입니다.

    | 장치 | 자리 | 켜지면 |
    |-|-|-|
    | 난방기 | 왼쪽 벽 방열기 | 방열판이 주황으로 달아오르고 더운 공기가 올라감 |
    | 냉방기 | 뒷벽 위 에어컨 | 바람 구멍이 파랗게 빛나고 찬 공기가 내려옴 |
    | 환기팬 | 오른쪽 벽 | 날개가 주황색으로 돎 |
    | 가습기 | 앞 왼쪽 바닥 | 안개가 피어오름 |
    | 제습기 | 앞 오른쪽 바닥 | 위 팬이 돌고 주변 습기를 빨아들임, 초록 표시등 |
    | 인공조명 | 작물 위 LED 등 | 밝기만큼 빛나고 빛 기둥이 내려옴 |
    | 급수 | 뒤 왼쪽 물탱크와 배관 | 배관이 파래지고 물방울이 떨어짐 |
    | 비료 | 뒤 오른쪽 양액 탱크 | 탱크가 초록빛으로 빛나고 알갱이가 뿌려짐 |

  - 병충해가 생기면 흙 위로 벌레가 기어 다니고 작물 위로 날벌레 떼가 맴돕니다. 격리되면 그 온실 유리가 붉어지고 지붕 아래 차광막이 쳐지며, 방제 약제 안개가 주기적으로 뿌려집니다.
  - 마스코트 **새싹봇**(머리에 새싹이 난 흰 로봇)이 온실 사이 통로를 순찰합니다. 병충해가 생기면 그 온실 앞으로 달려가 펄쩍펄쩍 뛰며 말풍선으로 알리고, 말풍선을 누르면 그 구역으로 카메라가 갑니다. 방제가 끝나면 "방제 완료!"라고 말하고 순찰로 돌아갑니다.
  - 수확하면(자동·직접 모두) 그 온실에서 작물 모양(상추·토마토·딸기·파프리카·오이·시금치)이 솟아올라 지붕 위로 떠오르고, **매출·수확량·품질·순이익**이 떠올랐다 사라집니다.
  - 장치에 마우스를 올리면 이름·켜짐·자동/수동·**지금 그 상태인 이유**(예: `15.0°C < 15°C`)가 뜹니다.
  - 전체 보기에서는 고르지 않은 구역 이름표가 `● 구역3`처럼 작게 나옵니다 (빨간 `!`는 격리·고사).
- **구역 카드**에는 상태, 생육 단계, 건강·생장 막대만 간단히 나옵니다. 누르면 그 구역이 선택되고 오른쪽에 상세가 나옵니다.
- **장치 제어** (상세 맨 위): 장치 8개의 켜짐과 이유가 나오고, `자동 / 켜기 / 끄기`로 **수동 운전**할 수 있습니다. 수동인 장치는 주황 테두리로 표시되고 `자동`을 누르면 다시 스스로 판단합니다. 급수·비료는 켜 둘 수 없어서 `자동 / 끄기`와 **지금 주기**가 있습니다.
- **24시간 그래프**: 초록 띠는 적정 범위, 회색은 밤입니다. 마우스를 올리면 그 시각의 값이 나오고, 범위를 벗어난 값은 빨간 글씨와 `범위 밖`으로 표시됩니다.
- **작물 고르기** : 목록에 작물마다 *지금 시세로 심었을 때의 하루당 예상 순이익*이 나오고, 가장 큰 작물을 **추천**합니다. 자동 재파종도 이 추천 작물을 심습니다.
- **심기** : 빈 구역에 고른 작물을 심습니다. 지금 할 수 없는 버튼은 흐리게 보이고, 누르면 왜 안 되는지 알려 줍니다.
- **수확 / 정리** : 다 자란 작물을 수확하거나, 죽은 작물을 치웁니다.
- **수확 가능한 구역 모두 수확** : 이름 그대로입니다.
- **갈아엎기** : 자라는 중이든 병들었든 수확 없이 밭을 비웁니다. 살아 있는 작물이면 한 번 더 묻습니다.
- **수확 기록** : 위에 **일별 정산** 그래프(매출·비용·순이익, 끝난 재배 기준)가 있습니다.
- **로그** : `전체` 또는 구역별로 골라 볼 수 있습니다. 주황색 줄은 경고입니다.
- **경고 알림** : 병충해·고사·방제 실패 같은 경고가 생기면 오른쪽 아래에 잠깐 뜨고, 위쪽 🔔에 안 읽은 개수가 붙습니다. 알림을 누르면 그 구역으로 카메라가 갑니다.

### 작물 설정
- 작물마다 적정 범위를 고치고 **저장**하면, 그 작물이 자라는 구역과 앞으로 심을 작물에 바로 적용됩니다(장치가 새 기준으로 켜고 끔). 초기화해도 남고, **기본값으로**로 되돌립니다.

### 시뮬레이터 (위쪽 검은 띠)
- **정지 / 시작**, **10분 진행**(한 단계씩), **초기화**
- **속도** : `1초 = 10분 / 1시간 / 3시간 / 8시간` 중에서 고릅니다. 옆에 하루가 현실로 몇 초인지 나옵니다.
- **계절** : 1년을 120일(계절당 30일)로 줄여서 봄→여름→가을→겨울이 돌아갑니다. 계절에 따라 바깥 평균기온(여름 +10°C, 겨울 −10°C)과 낮 길이(10~14시간)가 바뀝니다. 버튼을 누르면 그 계절 한가운데로 건너뜁니다.
- **바깥 날씨** : 한파·폭염을 걸어서 냉난방이 잘 대응하는지 시험합니다.
- **병충해** : 구역을 골라 병충해를 일으키면, 구역 격리 → 방제 → 해제 과정을 볼 수 있습니다.

### 모바일 앱
- **홈** : 수확 가능·주의 구역 수, 정산 요약, 구역 목록. 구역을 누르면 상세 화면으로 갑니다.
- **CCTV** : 선택한 구역을 3D 카메라로 가까이 봅니다. 아래에서 구역을 바꿉니다.
- **구역** : 생장·건강, 비용, 환경 값 6개, 장치 상태·수동 제어, 수확·갈아엎기 버튼
- **알림** : 경고 로그 모음 (최근 것부터)

관리 패널과 모바일 앱은 항상 같은 구역을 가리킵니다.

## 5. Git과 GitHub 처음 쓰기

### Git이 뭔가요?

- **Git** : 내 컴퓨터에서 코드의 **변경 기록을 저장**하는 프로그램입니다. "게임 세이브 포인트"라고 생각하면 됩니다. 잘못 고쳐도 예전 세이브로 돌아갈 수 있습니다.
- **GitHub** : 그 기록을 **인터넷에 올려 팀원과 공유**하는 사이트입니다.

### 꼭 알아야 할 단어

| 단어 | 뜻 |
|-|-|
| 저장소 (repository, repo) | 프로젝트 폴더 + 변경 기록 전체 |
| 커밋 (commit) | 세이브 포인트 하나. "무엇을 왜 바꿨는지" 메시지를 붙임 |
| 브랜치 (branch) | 갈래. 내 작업을 다른 사람 작업과 섞이지 않게 따로 진행하는 공간 |
| `master` | 기본 브랜치. **항상 실행되는 상태**로 유지합니다 |
| push | 내 커밋을 GitHub에 올리기 |
| pull | GitHub의 최신 커밋을 내 컴퓨터로 받기 |
| PR (Pull Request) | "내 브랜치를 master에 합쳐 주세요"라는 요청. 팀원이 코드를 보고 합침 |
| 충돌 (conflict) | 두 사람이 같은 줄을 다르게 고쳐서 Git이 어느 쪽을 쓸지 모르는 상황 |

### 처음 한 번만 하는 설정

커밋에 누가 작성했는지 이름이 남습니다. GitHub에 가입한 이메일을 쓰세요.

```bash
git config --global user.name "내 이름 또는 GitHub 아이디"
git config --global user.email "GitHub에 가입한 이메일"
```

처음 `git push`를 하면 브라우저 창이 떠서 GitHub 로그인을 요청합니다. 로그인하면 그다음부터는 묻지 않습니다.

## 6. 매일 하는 작업 순서

**규칙: `master`에서 바로 작업하지 말고, 할 일마다 브랜치를 새로 만듭니다.**

```bash
# ① master로 가서 최신 코드 받기 (작업 시작 전 매번!)
git switch master
git pull

# ② 내 작업용 브랜치 만들기 (이름은 영어로, 무슨 작업인지 알 수 있게)
git switch -c add-pepper-crop

# ③ 코드 고치기 → 실행해서 잘 되는지 확인 (2장 참고)
python -m server

# ④ 무엇이 바뀌었는지 확인
git status          # 바뀐 파일 목록
git diff            # 바뀐 내용 자세히

# ⑤ 세이브할 파일 고르기 → 커밋
git add core/catalog.py
git commit -m "작물에 고추 추가"

# ⑥ GitHub에 올리기 (이 브랜치를 처음 올릴 때만 -u origin 브랜치이름)
git push -u origin add-pepper-crop
```

⑦ GitHub 저장소 페이지에 들어가면 노란 띠로 **`Compare & pull request`** 버튼이 보입니다.
   눌러서 무엇을 바꿨는지 적고 **`Create pull request`**.

⑧ 팀원이 코드를 확인하고 **`Merge pull request`** 를 누르면 master에 합쳐집니다.
   합쳐진 뒤에는 ①부터 다시 시작하세요.

### VS Code로 하고 싶다면

왼쪽의 갈래 모양 아이콘(Source Control, `Ctrl + Shift + G`)에서 같은 일을 버튼으로 할 수 있습니다.
- 파일 옆 **`+`** = `git add`
- 위 입력칸에 메시지 쓰고 **`✓ Commit`** = `git commit`
- **`Sync Changes`** / **`Publish Branch`** = `git push` / `git pull`
- 왼쪽 아래 상태 표시줄의 브랜치 이름을 누르면 브랜치를 바꾸거나 새로 만들 수 있습니다.

### 좋은 커밋 습관

- **작게, 자주** 커밋하세요. "기능 하나 = 커밋 하나"가 좋습니다.
- 메시지는 **무엇을 했는지** 알 수 있게: `ai`, `수정` ❌ → `토마토 적정 온도 범위 조정` ✅
- 커밋 전에 **꼭 실행해 보세요.** 안 돌아가는 코드를 master에 합치면 모든 팀원이 멈춥니다.
- 비밀번호, 개인 정보, `__pycache__/`·`node_modules/`·`web/dist/` 같은 자동 생성 파일은 올리지 않습니다. (`.gitignore`에 적힌 파일은 Git이 무시합니다.)

## 7. 자주 겪는 문제

**`python`을 찾을 수 없다고 나와요 / Microsoft Store가 열려요**
Python 설치 때 `Add python.exe to PATH`를 체크하지 않은 경우입니다. 설치 파일을 다시 실행해 `Modify`로 체크하거나, 지우고 다시 설치하세요. 설치 후에는 터미널을 새로 열어야 합니다.

**`git push`가 `rejected` 되며 거절돼요**
GitHub에 내가 아직 받지 않은 커밋이 있다는 뜻입니다. `git pull`로 받은 다음 다시 `git push` 하세요.

**`git pull` 후 `CONFLICT`(충돌)이 났어요**
당황하지 말고 VS Code로 해당 파일을 엽니다. 이런 표시가 보입니다.

```
<<<<<<< HEAD
내가 고친 내용
=======
다른 사람이 고친 내용
>>>>>>> master
```

VS Code가 위에 띄워 주는 `Accept Current`(내 것) / `Accept Incoming`(상대 것) / `Accept Both`(둘 다) 중 하나를 누르거나 직접 맞게 고친 뒤, `<<<<<<<` `=======` `>>>>>>>` 표시가 모두 없어졌는지 확인하고:

```bash
git add 충돌난파일.py
git commit
```

잘 모르겠으면 혼자 해결하려 하지 말고 팀원에게 물어보세요. 같은 파일 같은 부분을 여러 명이 동시에 고치지 않도록 **작업 전에 누가 무엇을 할지 나눠 두면** 충돌이 크게 줄어듭니다.

**커밋하기 전에 고친 내용을 전부 되돌리고 싶어요**

```bash
git restore 파일이름.py      # 그 파일을 마지막 커밋 상태로 (고친 내용은 사라짐!)
```

**지금 어느 브랜치에 있는지 모르겠어요**

```bash
git branch          # * 표시가 붙은 것이 현재 브랜치
git log --oneline   # 최근 커밋 목록 (q를 누르면 빠져나옴)
```

**브라우저에 `{"detail":"Not Found"}`만 나와요**
화면을 아직 빌드하지 않은 경우입니다. `cd web` → `npm install` → `npm run build` 후 서버를 다시 켜세요.

**화면이 "농장에 연결하는 중…"에서 멈춰요**
서버가 켜져 있는지(개발 모드라면 `uvicorn`도 켰는지) 확인하세요. 서버를 다시 켜면 로그인부터 다시 해야 합니다.

**3D 온실이 안 보여요**
브라우저의 하드웨어 가속(WebGL)이 꺼져 있으면 안 그려집니다. 크롬 설정 → 시스템 → "가능한 경우 그래픽 가속 사용"을 켜세요.
